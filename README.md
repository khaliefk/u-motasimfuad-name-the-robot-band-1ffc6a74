Entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74): one funny name for a band made of robots, plus a few words on its hit song, all under 200 characters.

## Entry

> The Roomba Stones — hit single 'I Can't Get No (Battery) Satisfaction', recorded live from the charging dock.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
